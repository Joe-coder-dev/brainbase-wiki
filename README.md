# BrainBase Wiki

The static site behind **[wiki.brainbase.no](https://wiki.brainbase.no)** — guides for BrainBase
consultants. Built with [Docusaurus 3](https://docusaurus.io/).

## Develop

Node 24.15.0 (`.nvmrc`).

```bash
npm ci      # not `npm install` — deps are pinned exactly
npm start   # localhost:3033, live reload
```

## Content

Markdown in `docs/`, one folder per navbar section: `consultant-wiki/` (Konsulentwiki),
`network-contributions/` (Bidra i nettverket), `meetups/` (Meetups). Mostly Norwegian.

The sidebar is autogenerated from the folder structure, so adding a file is enough. Ordering and
section titles come from each folder's `_category_.json`. Images go in `static/img/`. Frontmatter
needs `id`, `title` and `description`.

**Heading anchors are a public API.** The platform and automated consultant emails deep-link into
these pages, and Docusaurus derives anchor ids from heading text — rewording a heading breaks those
links. Pin it instead:

```markdown
### Some heading {#the-original-anchor-id}
```

## Deploy

Merging to `main` ships to production. Nothing to run by hand.

```bash
npm run build   # -> build/
npm run serve   # preview the built site
```

`onBrokenLinks: 'throw'` means a broken internal link fails the build rather than shipping.
